# PM Skill Registry (spec §5)

Names below are workflow contracts. Only rows marked **implemented** exist as a `SKILL.md`; others are planned and must not be invoked as if installed.

| Skill | Status | Trigger / input | Output | Gate / condition |
|---|---|---|---|---|
| `intake-feedback` | **implemented (foundation)** | feedback + source + module; raw text or a readable allowlisted link | Intake Record: split parts, missing context, sensitive flags, duplicate candidates | local Draft only; no external ticket |
| `map-requirements` | **implemented (phase 2)** | validated Intake Record + requirement/decision/task snapshot | Mapping Record: per part exact/partial/gap/conflict/unknown, candidates, existing tasks, blockers, proposed_action | keyword ≠ committed scope; conflict → ask_owner; check/done task needs QA or release evidence; no create action |
| `breakdown-feature` | **implemented (phase 3)** | validated Mapping Record (+ human DEV.G2 approval record for official output) | Breakdown Record: problem, stories with G/W/T AC, role handoffs, task proposals (payload previews) | no DEV.G2 record → all hypothetical, no official handoff; no estimate/owner/sprint fields exist |
| `create-asana-tasks` | **implemented (phase 3, proposal-only)** | validated Breakdown Record + project/parent + human DEV.G3 and action approval records | Payload Preview Record: exact payload + sha256, diff, side effects, duplicate check, create/update/link/no_op/blocked | write adapter disabled; create/update only with DEV.G3 + action approval whose payload_hash matches; manual entry by human |
| `evaluate-pm-output` | **implemented (phase 3, advisory)** | any Draft record | Evaluation Record: policy check, 5 immediate-fail checks, 6 rubric criteria (agent_level advisory), verdict | `human_level` always null; pass_advisory grants nothing |
| `draft-prd` | planned (later) | approved problem + direction | PRD WHAT/WHY, scope, AC, tracking questions | DEV.G2 before detailed PRD |
| `summarize-sprint-status` | planned (later) | Asana scope + QA evidence | timestamped status/risk/open questions | Done ≠ production; no status change |
| `update-docs-on-completion` | planned (later) | done task + QA/release evidence + doc version | proposed doc diff | owner approves diff and a separate write order |
| `draft-stakeholder-update` | planned (later) | verified status + audience + instruction | draft update | sponsor drafts need Tom's prior permission; send approved separately |

Canonical location: `roles/pm/skills/<name>/`. Runtime copies: `.claude/skills/<name>/` and `.agents/skills/<name>/`, generated by `kit-cli.py sync --write` and verified by `sync --check`.
