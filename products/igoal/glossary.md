# iGoal Glossary (minimal, for intake routing)

| Term | Meaning in this Kit | Note |
|---|---|---|
| O / KR | Objective / Key Result (top-level goal and its measurable results) | |
| E / KS | Sub-structure under O (E) with its key steps/sub-results (KS) | hierarchy O→KR, E→KS; "cấp O" ≠ "cấp E" — never infer one from the other |
| Check-in | periodic progress update on a KR/KS | |
| Báo cáo | report view (write and read modes exist — always ask which) | |
| EKS | performance/evaluation-related data of individuals | **sensitive zone**; never transcribe |
| Pilot Feedback sheet | S6; feedback rows with reporter's own priority label (Cao/Thấp) and a status column | label ≠ severity; empty status ≠ nobody handled |
| Check (Asana section) | "completed, awaiting QA review" | not production evidence |
| DEV.G1–G5 / OPS.O1–O4 | workflow gates (core) | ≠ Project Plan milestones G1–G10 |
| Hoàn thiện (sheet) | status word in sheets | not release evidence |
